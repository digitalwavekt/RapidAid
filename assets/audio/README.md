# Audio Assets

Place pre-recorded voice instruction MP3 files here.

Naming convention: `{emergency_id}_step{number}.mp3`

Examples:
- heart_attack_step1.mp3
- heart_attack_step2.mp3
- snake_bite_step1.mp3
- drowning_step1.mp3

Each audio file should be:
- Format: MP3
- Duration: 5-10 seconds per step
- Language: English and Hindi versions
- Quality: 128kbps minimum
