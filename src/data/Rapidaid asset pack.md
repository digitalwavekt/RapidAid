## SAFETY RULES (strictly followed)
- ❌ NO blood, gore, open wounds shown
- ❌ NO water given to unconscious person
- ❌ NO forced vomiting
- ❌ NO ice directly on burns
- ❌ NO sucking snake venom
- ✅ Always call 108 first where critical
- ✅ Calm, clear, simple language
- ✅ Indian context (names, settings, clothing)

## 2. CPR (cpr)

---

### Step 1
- **Hindi text:** मरीज़ को सख्त ज़मीन पर सीधा लिटाएं। देखें कि वो सांस ले रहे हैं या नहीं। तुरंत 108 पर कॉल करें।
- **English text:** Lay the person flat on a firm surface. Check if they are breathing. Call 108 immediately.

### Audio TTS Generation
Use any of these TTS services to generate MP3 files from the text above:
- **Google TTS** (`gTTS` Python library) — Free, Hindi + English supported
- **ElevenLabs** — High quality, calm voice
- **Amazon Polly** — `Aditi` voice for Hindi, `Joanna` for English
- **Microsoft Azure TTS** — `hi-IN-SwaraNeural` for Hindi

**TTS Python script stub:**
```python
from gtts import gTTS
import os

# Example for one step
text = "तुरंत 108 पर कॉल करें। मरीज़ को शांत रखें।"
tts = gTTS(text=text, lang='hi', slow=False)
os.makedirs("assets/audio/hi/heart_attack", exist_ok=True)
tts.save("assets/audio/hi/heart_attack/step_1.mp3")
```
